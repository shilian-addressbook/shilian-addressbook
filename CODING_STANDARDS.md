# Coding Standards

- Use four spaces for Python indentation and snake_case for names. Use two spaces for front-end indentation and camelCase for variables and functions.
- Keep page rendering, contact state, and workbook conversion separate. Display contact data through DOM text nodes.
- When the workbook format changes, update the importer, exporter, README, and round-trip tests together.
- Keep each commit focused on one verifiable change. Use an English commit message that describes the change. Ask a teammate to review the pull request and run the relevant checks before merging.
- Use fictional contact details for testing and demonstrations.
